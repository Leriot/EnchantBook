# EnchantBook

EnchantBook brings enchanting recipes, material costs, and local enchanters into one window for World of Warcraft Forever. Open it with /eb on any character, regardless of profession.

- Open an Enchanting link from Trade chat to save the player's name and known recipes.
- Find enchanters in your faction and ruleset, check when they were last seen, and open a whisper.
- Highlight equipped slots missing a permanent enhancement or filter the book to those slots. Armor kits, leg patches, and other permanent enhancements count.
- Browse enchants, crafted items, and temporary buffs. Sort by slot or name and filter by skill bracket, role, or stat.
- Save material prices from Auction House searches and see the source and age beneath each estimate.

## Install

1. Download the EnchantBook ZIP attached to the latest GitHub release.
2. Extract the EnchantBook folder into your WoW Forever Interface/AddOns directory.
3. Start or restart WoW and enter /eb.
